# আউরা ক্যালকুলেটর (Aura Calculator) — Flutter Edition

**আউরা ক্যালকুলেটর (Flutter Edition)** হলো রিয়েল-টাইম `BackdropFilter` গ্লাসমরফিজম, ৩ডি পার্সপেক্টিভ আইকন অ্যানিমেশন এবং ৩টি কাস্টম ইউআই থিমসমৃদ্ধ সম্পূর্ণ বাংলা ক্যালকুলেটর ও ডেইলি টুলস অ্যাপ।

## গিটহাবে আপলোড করে অটোমেটিক APK বিল্ড করার নিয়ম
1. `AuraCalculator-Flutter-GitHub-Ready.zip` ফাইলটি **Unzip (Extract)** করুন।
2. GitHub-এ নতুন একটি Repository খুলে আনজিপ করা সব ফাইল ও ফোল্ডার (`.github`, `assets`, `lib`, `pubspec.yaml` ইত্যাদি) আপলোড বা পুশ করুন।
3. রিপোজিটরির **Actions** ট্যাবে গেলে **"Build Aura Calculator Flutter APK"** ওয়ার্কফ্লোটি অটোমেটিক চালু হবে এবং কয়েক মিনিটের মধ্যে **Artifacts** সেকশনে **`Aura-Calculator-Flutter-APK`** (`app-release.apk`) তৈরি হয়ে যাবে!
